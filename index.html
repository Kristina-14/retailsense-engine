How the forecast is generated
The model uses 17 features including 1/7/14/30-day revenue lags, rolling averages, day-of-week patterns, month, quarter, and Q4 flags. It predicts each day sequentially — tomorrow's prediction becomes input for the day after. The shaded band represents a ±15% confidence interval. The model retrains automatically every day on 1,000 new transactions via GitHub Actions.
